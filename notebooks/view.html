    🔐 Авторизация HTTP API

    Запросы к /api/* требуют заголовок Authorization: Bearer <token> (если apiAuthRequired).

    1. Токен из viewer — войдите, вкладка API → «Токен для API» → Копировать.
    2. Логин API — POST /api/auth/login → поле token.
    3. API_SECRET — серверный секрет из .env.

    Команды робота — только для активного зрителя в очереди.

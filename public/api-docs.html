🔐 Авторизация

Если на сервере включена авторизация, передавайте заголовок Authorization: Bearer <token> для запросов к /api/*.

  1. Токен из viewer — войдите на viewer, откройте вкладку API в пульте и скопируйте «Токен для API».
  2. Логин через API — POST /api/auth/login с username и password → поле token в ответе.
  3. API_SECRET — серверный секрет из .env (для админ-скриптов).

Команды робота работают только если вы активный зритель в очереди viewer. 

api = MegaminxClient("https://roborubiks.ru", api_token="ВАШ_ТОКЕН")
